# 🎮 Jogo da Forca


Jogo da Forca desenvolvido para praticar conceitos de desenvolvimento web e lógica de programação utilizando HTML, CSS e JavaScript.

O objetivo é descobrir a palavra antes que o tempo termine ou que o limite de erros seja atingido.

---

## ✨ Funcionalidades

- 🎲 Seleção aleatória de palavras
- 💡 Dicas para ajudar a descobrir a palavra
- ⏱️ Cronômetro de 60 segundos
- ❤️ Limite de 6 erros por partida
- ⌨️ Teclado virtual interativo
- ⌨️ Suporte ao teclado físico
- 🎨 Tema claro e escuro
- 🖼️ Desenho progressivo da forca
- ✅ Mensagem de vitória
- ❌ Mensagem de derrota
- 🔄 Opção para iniciar uma nova partida

---

## 🚀 Como jogar

1. Abra o arquivo `index.html` no navegador.
2. Observe a dica apresentada na tela.
3. Escolha uma letra utilizando o teclado virtual ou o teclado do computador.
4. Se a letra estiver na palavra, ela será revelada.
5. Letras incorretas aumentam o número de erros.
6. Descubra a palavra antes de atingir 6 erros ou antes que o tempo termine.
